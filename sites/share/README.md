# Tan gift pages

Independent static HTML at https://share.tan.coffee, hosted in the `tan-studio-share` Vercel project in team `xroma`. The root page is the approved fictional gift-page example; it is marked as fictional and excluded from search indexing.

This directory has no notebook imports, credentials, runtime requests, page generator, or Studio publishing controls. Individually authored gift pages may be added as static directories containing an `index.html`. Only publish content deliberately chosen for public sharing. Store the resulting HTTPS URL on a roast through its existing gift-page link field.

## Preview

From this directory run `python3 -m http.server 4321 --bind 127.0.0.1`. Open http://127.0.0.1:4321.
