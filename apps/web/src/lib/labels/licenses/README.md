# Label fonts

Glyph outlines are bundled from OFL-licensed fonts to keep SVG/PNG/PDF output independent of installed fonts. Font sources and axes are retained in fonts.ts; license notices are included here. Label type is Courier Prime Regular (see courier-prime-OFL.txt), built by script/build_label_typewriter.py. The plant comes from logo.ts, generated by script/build_brand_assets.py from the approved master; never edit or redraw it.
